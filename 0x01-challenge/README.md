### Example Challenge

#### Problem Statement
Write a function that takes a list of integers and returns a new list with only the even numbers from the original list.

#### Input and Output
- **Input**: A list of integers, e.g., `[1, 2, 3, 4, 5, 6]`.
- **Output**: A list of even integers, e.g., `[2, 4, 6]`.

#### Example Cases
- **Input**: `[10, 21, 32, 43, 54]`
- **Output**: `[10, 32, 54]`

#### Solution in Python
```python
def filter_even_numbers(numbers):
    even_numbers = [num for num in numbers if num % 2 == 0]
    return even_numbers

# Test the function
print(filter_even_numbers([1, 2, 3, 4, 5, 6]))  # Output: [2, 4, 6]
print(filter_even_numbers([10, 21, 32, 43, 54]))  # Output: [10, 32, 54]
```
